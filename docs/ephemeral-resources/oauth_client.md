# tailscale_oauth_client (Ephemeral Resource)

The oauth_client ephemeral resource creates an OAuth client for temporary use. The client and its secret are deleted when Terraform closes the ephemeral resource. Requires Terraform 1.10 or later.

> **Note:** This ephemeral resource revokes the OAuth client when Terraform closes it. It is intended for temporary clients and is not suitable when the client must remain active after the Terraform operation. The managed resource keeps clients active, but its sensitive client secret is stored in Terraform state.

## Example Usage

```terraform
ephemeral "tailscale_oauth_client" "metrics" {
  description = "Temporary metrics client"
  scopes      = ["devices:core:read"]
}
```

## Schema

### Required

- `scopes` (Set of String) Scopes to grant to the client. See https://tailscale.com/kb/1623/ for a list of available scopes.

### Optional

- `description` (String) A description of the OAuth client consisting of alphanumeric characters. Defaults to `""`.
- `tags` (Set of String) Tags that access tokens generated for the OAuth client will be able to assign to devices. Mandatory if scopes include `devices:core` or `auth_keys`.

### Read-Only

- `created_at` (String) The creation timestamp in RFC3339 format.
- `id` (String) The OAuth client ID.
- `key` (String, Sensitive) The OAuth client secret. This value is ephemeral and is not stored in Terraform plan or state.
- `updated_at` (String) The updated timestamp in RFC3339 format.
- `user_id` (String) ID of the user who created this OAuth client.
