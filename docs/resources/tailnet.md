# tailscale_tailnet (Resource)

The tailnet resource allows you to create and delete API-only tailnets in an organization using the alpha tailnet creation API. Provider OAuth credentials require the tailnets scope. Import is not supported because deletion requires the OAuth credentials returned at creation.

The OAuth client secret is returned only once and is stored in Terraform state, even
though Terraform marks it sensitive. Protect access to state and do not revoke the
generated credentials while Terraform manages the tailnet. If those credentials
are lost or revoked, recover access through the creating tailnet or contact
Tailscale support before attempting deletion again.

## Example Usage

```terraform
resource "tailscale_tailnet" "example" {
  display_name = "Example Tailnet"
}
```

## Schema

### Required

- `display_name` (String) A custom display name for the API-only tailnet. The name must be unique within your organization. Changing this value replaces the tailnet.

### Read-Only

- `created_at` (String) The creation timestamp of the tailnet in RFC3339 format.
- `dns_name` (String) The DNS suffix used to construct fully qualified device names in this tailnet.
- `id` (String) The stable, globally unique identifier for the tailnet.
- `oauth_client_id` (String) The OAuth client ID returned when the API-only tailnet was created.
- `oauth_client_secret` (String, Sensitive) The OAuth client secret returned when the API-only tailnet was created. This is stored in Terraform state because the delete API requires tailnet-specific OAuth credentials.
- `org_id` (String) The stable, globally unique identifier for the organization.
